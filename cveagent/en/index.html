Report a problem and get help

Public support reports use the separate feichti01/cveagent-support repository. It contains no product source code or confidential operational data.

  • View public reportsSearch existing bugs and feature requests.
  • Create a bug reportStructured form on GitHub; a GitHub account is required.
  • Create a feature requestSuggest an improvement that can be discussed publicly.
  • Private request by emailFor questions involving personal or confidential information.
  • Report a vulnerability privatelyPlease do not submit security reports as public issues.

CVE Agent is maintained by one person in their spare time. You will normally hear back within seven days.

What to include in a report

  • macOS version and Mac model or chip.
  • CVE Agent version and build number shown in the app.
  • The selected time range, report scope and steps leading to the problem.
  • The visible error message without confidential reports or credentials.

Never publish tokens, API keys, tenant or customer identifiers, internal infrastructure details, or confidential CVE reports.

Availability

CVE Agent requires macOS 13 Ventura or later. Its Mac App Store release is in preparation. This support site does not distribute the app or an installer.

In-app help

The app includes local help for search, time range, report scope, refresh, priorities, filters, CVE details and background checks.
