Report a problem and get help

Public support reports use the separate feichti01/cveagent-support repository. It contains no product source code or confidential operational data.

  • View public reportsSearch existing bugs and feature requests.
  • Create a bug reportStructured form on GitHub; a GitHub account is required.
  • Create a feature requestSuggest an improvement that can be discussed publicly.
  • Private request by emailFor questions involving personal or confidential information.
  • Report a vulnerability privatelyPlease do not submit security reports as public issues.

CVE Agent is maintained by one person in their spare time. You will normally hear back within seven days.

What to include in a report

  • macOS version and Mac model or chip.
  • CVE Agent version and build number shown in the app.
  • The selected time range, report scope and steps leading to the problem.
  • The visible error message without confidential reports or credentials.

Never publish tokens, API keys, tenant or customer identifiers, internal infrastructure details, or confidential CVE reports.

Availability

CVE Agent requires macOS 13 Ventura or later and is available on the Mac App Store. This support site does not distribute the app or an installer.

Fixed in 1.17: background check did not start on Macs that had an earlier TestFlight build (1.15.2–1.16.2)

As of: September 22, 2026. In versions 1.15.2 through 1.16.2 the background service did not start on Macs that previously had a TestFlight pre-release installed: macOS had stored the service’s launch constraint at its first registration and kept it unchanged for later App Store installations – even after a complete uninstall. The service was terminated at start-up although the app reported it as “enabled”. Installations made only from the App Store were not affected.

Fix in version 1.17: The service is registered under a new identifier and therefore gets a fresh record without the outdated constraint. In addition, the app runs the hourly check itself while it is open, shows in the menu which component performed the last check, and warns when the service does not start. Until the update, affected Macs can run sudo sfltool resetbtm in Terminal and restart while only the App Store version is installed (all apps will ask once more for permission for their login items).

Diagnosis in Terminal (1.16.2): launchctl print gui/$(id -u)/at.feichtinger.cveagent.daemon | grep -E "last exit|job state" – affected systems show OS_REASON_CODESIGNING and spawn failed. History: report #1.

Release notes

1.17.0 (build 41) – in preparation

  • Dynamic vendor watchlist: On every run, vendors that appear in CISA KEV or CERT-Bund advisories within the last 365 days, or that have at least ten CVEs with EPSS ≥ 0.1, are added to the 270 curated vendors automatically. They are marked with ⟳ in the report, remain for 90 days after their last signal, the data-state section shows their count per source, and exports carry the origin. Can be disabled under Settings › Sources.
  • Hourly check inside the app: While the app is open it checks on its own when the background service is not running; the menu shows which component performed the last check and warns when the service does not start. The service is re-registered cleanly on update.
  • Help: justified text, more spacing between sections, new section on dynamic vendors.

1.16.2 (build 38) – September 2026

  • Favorites: star CVEs (up to 16). Favorites stay in the catalog permanently, appear in every report regardless of the time range and can be exported as Markdown and CSV; the background check notifies you about changes to favorites (CVSS, KEV, EPSS, CERT-Bund).
  • Vendor filter with multiple selection: a searchable list replaces the single choice and the selection is kept. Mark up to 16 vendors as “My vendors”; the background check reports new critical CVEs at these vendors separately.
  • Menu action “Show new critical CVEs”: shows exactly those CVEs; time range and scope adjust automatically – also when clicking the notification.
  • New source CERT-Bund (BSI): public CSAF advisories enrich matching CVEs with the German federal rating, affected products, remediations and references – shown as CERT-Bund values next to NVD, EPSS and KEV; rolling sync of the last 30 days, no historic import. Can be switched off at any time under Settings › Sources; CERT-Bund links open the advisory’s portal page.
  • Interface for macOS 26/27 (Liquid Glass): the menu bar item is a system menu with keyboard shortcuts, help opens in its own window, toolbar and settings use system controls. macOS 13–15 keep the previous appearance.
  • Report: wider and smoother; when more findings exist than the report limit, a notice explains the deliberate selection by risk; the English view shows status values, reasons and actions in English; text contrast raised to WCAG AA; CERT-Bund is retried on brief network hiccups.

Earlier versions: 1.15.2 (risk selection for large reports, first-sync view, copy function), 1.15.1 (first Store release).

In-app help

The app includes local help for search, time range, report scope, refresh, priorities, risk selection, filters, favorites, vendor selection, dynamic vendors (automatic inclusion from CISA KEV, CERT-Bund and EPSS, ⟳ marker, switch in Settings), CVE details, CERT-Bund data and background checks.
