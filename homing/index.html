Homing-Support

Support für Homing, die Menüleisten-App für macOS, die AirPods, Beats und andere Bluetooth-Kopfhörer mit einem Klick oder einem Tastenkürzel wieder mit dem Mac verbindet.

Fehler melden und Meldungen einsehen

Supportmeldungen und Fehlerberichte laufen über die öffentliche Issue-Liste im Repository feichti01/support. Meldungen zu Homing tragen das Label homing. Die Liste ist ein kurzer englischer Auszug der öffentlich kommunizierbaren Punkte und keine vollständige Statusquelle.

  • Öffentliche Fehlerliste ansehen Offene, öffentlich gespiegelte Bugfixes von Homing auf GitHub.
  • Neue Supportmeldung erstellen Neues Issue auf GitHub anlegen; dafür wird ein GitHub-Konto benötigt.
  • Nicht öffentliche Anfrage per E-Mail Für Fragen, die personenbezogene Daten enthalten, oder wenn Sie kein GitHub-Konto verwenden möchten.
  • Sicherheitslücke melden Bitte per E-Mail mit dem Betreff homing security, nicht öffentlich.

Homing wird von einer Person in der Freizeit gepflegt. Antworten erfolgen nach Möglichkeit innerhalb von sieben Tagen.

Was eine Meldung enthalten sollte

  • macOS-Version und Chip (Apple-Menü > Über diesen Mac).
  • Homing-Version (Finder > /Programme/Homing.app auswählen > Informationen) und Bezugsquelle: Mac App Store oder .pkg von GitHub.
  • Modell der Kopfhörer.
  • Was Sie angeklickt haben und was passiert ist. Wenn möglich die passenden Zeilen aus der Konsole.app, gefiltert nach Homing.

Veröffentlichen Sie in Issues keine Passwörter, Zertifikate oder Geräteadressen anderer Personen.

Download und Quellcode

  • Homing im Mac App Store Kostenlos, automatische Updates über den App Store.
  • Signiertes und notarisiertes Installationspaket Direktdownload als .pkg aus dem Releases-Repository.
  • Quellcode auf GitHub Open Source unter der MIT-Lizenz.

Homing benötigt macOS 13 Ventura oder neuer. Nur die jeweils aktuelle Version erhält Fehlerkorrekturen.
