MultihomingGuard Support

Support for MultihomingGuard, the macOS menu-bar app that prevents Wi-Fi and wired LAN from being used at the same time: when a cable is connected, Wi-Fi is turned off; when the cable goes away, Wi-Fi comes back.

Report a problem and review reports

Support requests and bug reports go through the public issue list in the feichti01/support repository. MultihomingGuard reports carry the label multihomingguard. The list is a short English extract of the publicly shareable items and not a complete status source.

  • View the public bug list Open, publicly mirrored MultihomingGuard bug fixes on GitHub.
  • Create a new support report Opens a new GitHub issue; a GitHub account is required.
  • Private request by email For questions involving personal data or internal network details, or if you prefer not to use a GitHub account.
  • Report a security vulnerability By email with the subject multihomingguard security, please, not in public.

MultihomingGuard is maintained by one person in their spare time. You will normally hear back within seven days.

What to include in a report

  • macOS version and chip (Apple menu > About This Mac).
  • MultihomingGuard version (shown under the title in the app's menu, or Finder > select /Applications/MultihomingGuard.app > Get Info).
  • Which network adapters are involved: built-in Wi-Fi, the Mac's Ethernet port, USB, Thunderbolt or dock adapters (vendor and model).
  • What you expected and what happened instead. If possible, the relevant lines from /var/log/com.local.multihomingguard.log and /var/log/com.local.multihomingguard.err (reachable from the app's menu via "Logs im Finder oeffnen").

Never post passwords, Wi-Fi keys, internal host names or your employer's network addresses in public issues.

Distribution and source code

MultihomingGuard is not distributed through the Mac App Store. The developer hands out the ready-built MultihomingGuard.app directly; it runs without developer tools, and the background service is bundled inside the app. The source repository is not public at this time.

MultihomingGuard requires macOS 13 Ventura or later. Only the latest version receives fixes.

How the app works

  • When a wired LAN adapter is properly connected (link, enabled network service and a valid IPv4 address), Wi-Fi is turned off.
  • When only Wi-Fi is connected, the LAN network services stay enabled so that a newly attached dock or cable gets link and DHCP immediately.
  • When neither LAN nor Wi-Fi is connected, LAN services are enabled and Wi-Fi is turned on.
  • The check runs every two seconds in a background service (LaunchDaemon) with root privileges, because macOS only allows network services to be changed that way. The menu-bar app shows the status and controls the service. The app's interface is in German.
