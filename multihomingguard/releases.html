Versionen und Änderungen

Deutsch

Stand: 2. Oktober 2026

Die App aktualisiert sich selbst: Liegt eine neue Version vor, zeigt das Menü Version … verfügbar, und ein Klick lädt und installiert sie ohne Passwortabfrage. Die vollständige Angabe lautet Version.Build, etwa 2.0.3.153 — die Buildnummer zählt jede Änderung am Quellcode, die Version steht für den Funktionsumfang.

2.0.3 — 2. Oktober 2026

  • „Was ist neu?" öffnet jetzt wirklich. Der Verweis wurde angezeigt, ein Klick bewirkte aber nichts. Er öffnet die Seite nun zuverlässig — und erscheint auch dann, wenn das Update von einer älteren Version übergeben wurde.
  • Das Menü ist deutlich kürzer. Es zeigt nur noch Leitungen, die tatsächlich verbunden sind; leere Adapterzeilen, die technische Zusatzzeile und die Fußzeile entfallen im Normalbetrieb. Für den Support sind sie weiterhin erreichbar: Menü mit gedrückter ⌥ öffnen, oder Diagnose.

2.0.2 — 2. Oktober 2026

  • „Was ist neu?" beim Update. Wird eine neue Version angeboten, steht daneben ein Verweis auf genau diese Seite — und ebenso in der Meldung nach der Installation. Bisher gab es ihn nicht, obwohl die App die Adresse bereits mitführte.

2.0.1 — 1. Oktober 2026

Diese Version besteht fast vollständig aus Korrekturen, die bei einer Abnahme an echter Hardware gefunden wurden: ein Mac am Firmen-LAN, zusätzlich ein iPhone per USB-Kabel.

  • Das Kabel wird nach einem Wechsel wieder übernommen. Wurde ein per USB angestecktes iPhone geparkt, während ein LAN aktiv war, blieb es nach dem Abziehen des LAN-Kabels dauerhaft abgeschaltet — das WLAN übernahm, obwohl ein Kabelweg vorhanden war, und auch erneutes Anstecken half nicht. Ursache war, dass der Hintergrunddienst seine eigenen Änderungen an der Netzwerkkonfiguration nicht mehr sah.
  • Das WLAN-Symbol in der Menüleiste kommt zur Ruhe. Solange ein Kabel den Verkehr trug, arbeitete das Symbol dauerhaft, und macOS schaltete das Funkmodul immer wieder ab, während die App es für Apple Watch, AirDrop und Handoff wieder einschaltete. Das WLAN behält jetzt eine gültige Konfiguration ohne erreichbare Adresse, womit beides aufhört.
  • Selbst ausgeschaltetes WLAN bleibt aus — auch dann, wenn gerade ein Kabel verbunden ist. Zuvor wurde es nach etwa zehn Sekunden wieder eingeschaltet.
  • Ehrliche Meldung, wenn ein Update blockiert wird. Netzwerke, die Downloads prüfen und dabei neu signieren, verhindern das Laden des Pakets. Die App nennt jetzt, wer blockiert, statt nur „Download fehlgeschlagen" zu melden.
  • Eigenes Symbol für „Keine Verbindung". Es unterscheidet sich jetzt auch in der Form von einem WLAN, das Sie selbst ausgeschaltet haben — in der Menüleiste wird einfarbig gezeichnet, die Farbe allein genügte nicht.
  • Einfacher geworden: Die App wird von Benutzern selbst installiert. Zentrale Verwaltung über Konfigurationsprofile und der telefonische Einmalcode für den Support sind entfallen; eine Pause wird jetzt ausschließlich über die Administrator-Anmeldung von macOS freigegeben.

2.0.0 — September 2026

Neuaufbau der App. Die wesentlichen Punkte gegenüber Version 1:

  • Das Kabel wird geprüft, nicht nur gezählt. Eine Kabelverbindung gilt erst als funktionierend, wenn Link, Adresse und Gateway vorhanden sind und der Namensdienst dieses Netzes über genau diesen Anschluss antwortet.
  • Apple Watch, AirDrop und Handoff funktionieren weiter, während das Kabel den Verkehr trägt: Dem WLAN wird die Adresse entzogen, das Funkmodul bleibt eingeschaltet.
  • iPhone per USB zählt als Kabelweg und wird bei aktivem LAN geparkt, damit kein Datenvolumen verbraucht wird — über das Zahnrad abschaltbar.
  • VPN wird angezeigt, herstellerunabhängig, und auf Wunsch wird verhindert, dass ein Gerät am Kabel den Namensdienst des Firmen-VPN verdeckt.
  • Updates ohne Passwort, aus einem signierten Manifest, geprüft auf Signatur und Apple-Notarisierung.
  • Keine Datenerfassung. Alles bleibt auf dem Mac.

Bekannte Einschränkungen

  • Beim Wechsel auf einen Kabelweg behält das WLAN seine Adresse noch wenige Sekunden. Das ist beabsichtigt: Die Adresse wird erst entzogen, wenn der Kabelweg nachweislich funktioniert.
  • In Netzwerken, die Downloads aufbrechen, lässt sich das Update nicht laden. Laden Sie es dann in einem anderen Netz oder von der App-Seite.

English

Last updated: 2 October 2026

The app updates itself: when a new version exists, the menu shows Version … available, and one click downloads and installs it without a password prompt. The full designation is version.build, for example 2.0.3.153 — the build number counts every change to the source, the version stands for what the app does.

2.0.3 — 2 October 2026

  • "What's new?" actually opens now. The link was shown but a click did nothing. It opens the page reliably — and also appears when the update was handed over by an older version.
  • The menu is noticeably shorter. It lists only connections that are actually up; empty adapter rows, the technical extra line and the footer are gone in normal use. They remain available for support: open the menu with ⌥ held, or use Diagnose.

2.0.2 — 2 October 2026

  • "What's new?" with an update. When a new version is offered, a link to this very page sits next to it — and next to the message after installation. It did not exist before, although the app already carried the address.

2.0.1 — 1 October 2026

Almost entirely fixes, found during an acceptance test on real hardware: a Mac on a company LAN with an iPhone attached by USB cable.

  • A cable is picked up again after a switch. An iPhone parked while a LAN was active stayed switched off for good once the LAN cable was pulled — Wi-Fi took over although a cable was there, and plugging it back in did not help either. The cause was that the background service no longer saw its own changes to the network configuration.
  • The Wi-Fi icon in the menu bar settles down. While a cable carried the traffic the icon kept working, and macOS powered the radio down again and again while the app switched it back on for Apple Watch, AirDrop and Handoff. Wi-Fi now keeps a valid configuration without a reachable address, which ends both.
  • Wi-Fi you switch off stays off — including while a cable is connected. It used to come back on after about ten seconds.
  • An honest message when an update is blocked. Networks that scan downloads and re-sign them prevent the package from loading. The app now names who blocks instead of reporting a plain "download failed".
  • Its own symbol for "No connection". It now differs in shape from Wi-Fi you switched off yourself — the menu bar draws in a single colour, so colour alone was not enough.
  • Simpler: users install the app themselves. Central management through configuration profiles and the one-time support code over the phone are gone; a pause is now authorized solely through the macOS administrator dialog.

2.0.0 — September 2026

A rebuilt app. The main points compared with version 1:

  • The cable is verified, not merely counted. A wired connection only counts as working once link, address and gateway are there and that network's name service answers over that very adapter.
  • Apple Watch, AirDrop and Handoff keep working while the cable carries the traffic: Wi-Fi loses its address, the radio stays on.
  • iPhone over USB counts as a wired path and is parked while a real LAN is up, so no mobile data is used — switchable in the gear menu.
  • A VPN is shown, whichever vendor, and optionally a device on the cable is kept from shadowing the company's name service.
  • Updates without a password, from a signed manifest, checked for signature and Apple notarization.
  • No data collection. Everything stays on the Mac.

Known limitations

  • When switching to a wired path, Wi-Fi keeps its address for a few seconds. That is deliberate: the address is only removed once the wired path is proven to work.
  • On networks that break up downloads the update cannot be loaded. Load it on another network or from the app page instead.
