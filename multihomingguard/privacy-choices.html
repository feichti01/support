Datenschutz-Einstellungen für MultihomingGuard

Privacy Choices: was Sie auf Ihrem Mac selbst steuern können.

  • Deutsch

Deutsch

Stand: 18. September 2026

Kurzfassung: MultihomingGuard erhebt keine personenbezogenen Daten, verwendet kein Tracking, keine Analyse und keine Werbung und verbindet sich nie mit dem Internet. Es gibt daher nichts, dem Sie zustimmen oder widersprechen müssten, kein Konto zum Löschen und keine Daten, die Sie beim Entwickler anfordern könnten. Diese Seite listet, was Sie auf Ihrem Mac selbst kontrollieren.

1. Hintergrunddienst anhalten oder deinstallieren

Der Schutz läuft als LaunchDaemon mit Root-Rechten. Sie können ihn jederzeit anhalten oder vollständig entfernen:

  1. Öffnen Sie das Menü von MultihomingGuard in der Menüleiste und entsperren Sie den Bereich Admin Mode per Touch ID oder Anmeldekennwort.
  2. Wählen Sie Daemon stoppen, um den Schutz vorübergehend anzuhalten, oder Deinstallieren, um Dienst und Startdatei zu entfernen.
  3. macOS fragt nach Ihrem Administrator-Passwort. Die App sieht das Passwort nicht.

Beim Deinstallieren werden /usr/local/libexec/multihoming-guard und /Library/LaunchDaemons/com.local.multihomingguard.plist gelöscht. WLAN und LAN-Dienste bleiben im zuletzt gesetzten Zustand; schalten Sie WLAN bei Bedarf in den Systemeinstellungen wieder ein.

2. Autostart beim Anmelden

Wenn Sie den Autostart eingerichtet haben, entfernen Sie ihn im Admin-Bereich über Autostart entfernen. Dabei wird /Library/LaunchAgents/com.local.MultihomingGuardApp.plist gelöscht; die Kopie unter /Applications/MultihomingGuard.app bleibt bestehen und kann von Hand in den Papierkorb gelegt werden.

3. Protokolldateien

Der Dienst schreibt nach /var/log/com.local.multihomingguard.log und /var/log/com.local.multihomingguard.err. Die Dateien enthalten Zeitstempel, Adapter- und Dienstnamen sowie den Verbindungszustand, keine IP-Adressen, WLAN-Namen oder Passwörter. So löschen Sie sie:

  1. Stoppen Sie den Dienst über Admin Mode > Daemon stoppen.
  2. Löschen Sie beide Dateien im Terminal mit Administratorrechten:
sudo rm /var/log/com.local.multihomingguard.log /var/log/com.local.multihomingguard.err

Beim nächsten Start legt der Dienst die Dateien neu an. Die Dateien werden nie an den Entwickler übertragen; Sie entscheiden selbst, ob Sie Auszüge einer Supportmeldung beifügen.

4. Gespeicherte Einstellungen

MultihomingGuard speichert keine Einstellungen, keine Voreinstellungen und keinen Verlauf. Es gibt keinen Container, keine Preferences-Datei und keinen Keychain-Eintrag, den Sie löschen müssten.

5. Vollständig entfernen

  1. Im Admin-Bereich Deinstallieren und danach Autostart entfernen wählen.
  2. App über Quit beenden.
  3. /Applications/MultihomingGuard.app und gegebenenfalls die ursprünglich kopierte App in den Papierkorb legen.
  4. Optional die Protokolldateien wie unter Punkt 3 löschen.

Danach ist nichts von MultihomingGuard mehr auf Ihrem Mac vorhanden.

6. Supportseite und GitHub

Diese Seite setzt keine Cookies und lädt keine externen Skripte. GitHub Pages protokolliert IP-Adressen zu Sicherheitszwecken; das können Sie nur durch Nichtaufrufen der Seite vermeiden. Öffentliche Issues können Sie in Ihrem GitHub-Konto selbst bearbeiten oder löschen. Für alles andere genügt eine E-Mail an christian@feichti.at.

Privacy choices for MultihomingGuard

Effective: September 18, 2026

Summary: MultihomingGuard collects no personal data, uses no tracking, analytics or advertising and never connects to the internet. There is therefore nothing to consent to or object to, no account to delete and no data to request from the developer. This page lists what you control on your own Mac.

1. Stop or uninstall the background service

The guard runs as a LaunchDaemon with root privileges. You can stop or remove it at any time:

  1. Open the MultihomingGuard menu in the menu bar and unlock the Admin Mode area with Touch ID or your login password.
  2. Choose Daemon stoppen (stop daemon) to pause the guard, or Deinstallieren (uninstall) to remove the service and its launch file. The app's interface is in German.
  3. macOS asks for your administrator password. The app never sees it.

Uninstalling deletes /usr/local/libexec/multihoming-guard and /Library/LaunchDaemons/com.local.multihomingguard.plist. Wi-Fi and LAN services stay in their last state; re-enable Wi-Fi in System Settings if needed.

2. Launch at login

If you set up launch at login, remove it with the Autostart entfernen item in the admin area. This deletes /Library/LaunchAgents/com.local.MultihomingGuardApp.plist; the copy at /Applications/MultihomingGuard.app stays and can be moved to the Trash by hand.

3. Log files

The service writes to /var/log/com.local.multihomingguard.log and /var/log/com.local.multihomingguard.err. The files contain timestamps, adapter and service names and the connection state, but no IP addresses, Wi-Fi names or passwords. To delete them:

  1. Stop the service via Admin Mode > Daemon stoppen.
  2. Delete both files in Terminal with administrator privileges:
sudo rm /var/log/com.local.multihomingguard.log /var/log/com.local.multihomingguard.err

The service recreates the files on its next start. They are never sent to the developer; you decide whether to attach excerpts to a support request.

4. Stored settings

MultihomingGuard stores no settings, no preferences and no history. There is no container, no preferences file and no Keychain item for you to delete.

5. Remove completely

  1. In the admin area choose Deinstallieren and then Autostart entfernen.
  2. Quit the app with Quit.
  3. Move /Applications/MultihomingGuard.app and, if applicable, the originally copied app to the Trash.
  4. Optionally delete the log files as described in section 3.

Nothing of MultihomingGuard remains on your Mac afterwards.

6. Support site and GitHub

This page sets no cookies and loads no external scripts. GitHub Pages logs IP addresses for security; the only way to avoid that is not to visit the page. You can edit or delete your own public issues in your GitHub account. For everything else, an email to christian@feichti.at is sufficient.
